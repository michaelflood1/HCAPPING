### main units of human body

Cell
    - basic structure and functional unit of the body

**organelles** 

        - cell membrane
            - cell lining

        - cell nucleus
            - control center/ dna container

        - cytoplasm
            - fluid within cell membrane that supports the other organelles

Every cell requires water, breathes, digests, elimates waste, reproduces ( mitosis)

Chromosomes :

contained in nucleus

there are 46 in each human cell

Chromosomes contain genes

Genese control ingerited traits  i.e height colour skin colour inherited disease


Tissue
    - Cells that have similar function and structure form a tissue

Organs
    - Tissues that look the same and function the same make organs

Systems
    - Organs that work together
