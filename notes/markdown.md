
# 📚 Markdown Syntax Cheat Sheet for School Notes

## 1. Headings

# Main Topic
## Subtopic
### Smaller Topic
#### Even Smaller Topic

## 2. Bold

**Important term**

## 3. Italic

*Key idea*

## 4. Bold + Italic

***Very important***

## 5. Bullet Points

- First point
- Second point
  - Sub-point
  - Another sub-point

## 6. Numbered Lists

1. First step
2. Second step
3. Third step

## 7. Checklists

- [ ] Homework
- [ ] Study chapter
- [x] Completed assignment

## 8. Highlighting

==Important information==

> Note: Highlighting is supported by some Markdown apps but not all.

## 9. Block Quotes

> Important quote, definition, or teacher comment.

## 10. Inline Code

`print("Hello World")`

## 11. Code Blocks

```python
print("Hello World")
````

 ## 12\. Links

 Website Name

 ## 13\. Images

 ## 14\. Horizontal Divider

---

 ## 15\. Tables

 | Term | Definition |
| --- | --- |
| Photosynthesis | Process plants use to make food |
| Respiration | Process cells use to release energy |

 ## 16\. Superscript

 x^2^

 > Supported by some Markdown apps.

 ## 17\. Subscript

 H\~2\~O

 > Supported by some Markdown apps.

 ## 18\. Escape Markdown Characters

 \*This is not italic\*

 Use `\` before a Markdown character when you want it displayed normally.

 # 📝 Example School Notes

 # Biology — Cell Structure

 ## Key Terms

 - **Nucleus** — Controls the activities of the cell.
- **Mitochondria** — Produces energy for the cell.
- **Ribosome** — Makes proteins.

 ## Main Ideas

 1. Cells are the basic units of life.
2. Plant and animal cells have some structures in common.
3. Plant cells have structures that animal cells don't have.

 ## Important

 > The nucleus contains most of the cell's genetic material.

 ## Comparison

 | Structure | Plant Cell | Animal Cell |
| --- | --- | --- |
| Nucleus | ✅ | ✅ |
| Cell wall | ✅ | ❌ |

| Chloroplast | ✅ | ❌ |
| Cell membrane | ✅ | ✅ |

 ## To Review

 - [ ] Learn key terms
- [ ] Review cell diagrams
- [ ] Complete practice questions
